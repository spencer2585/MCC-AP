# Contributing
All contributions are welcome, however there are a few rules and things that may happen.
- All contributed code is expected to follow the guidelines laid out in the AP Discord
  - You must understand your code and what it does in more depth than just the high concept level
  - You are responsible for the code you contribute until it is merged into the repository
  - Your code must not be harmful either purposely or accidentally.
- Additionally, all contributed code will be reviewed before merging
- During the review process you may be asked to change the code you contribute
- additionally your code may be rejected or changed during or after being merged into the project
- Code should be commented for easier review
- AI use is allowed as long as you follow the above rules

All contributions should be made via a PR, If your code is a fix to an existing bug make the PR on the main branch.  
If your code adds something new it should be made to the current in dev update branch.
  
If you are looking to contribute please take a look at the following documentation  
APWorld Specs  
Game Module API  
Quality Standards
