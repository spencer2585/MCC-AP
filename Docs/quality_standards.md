# Quality Standards
## AI Code
As stated in the contributing doc, AI use is permitted as long as it follows all Quality standards and you understand the code being generated in detail.  
Understanding what the code is doing is not enough, you need to understand how its doing it and why it is doing it that way  
A good standard to follow: If during review of your contribution you are questioned about any section of code will you be able to defend what is written and why its done that way.
