# AI Usage Disclosure
AI is used heavily in this project's development, but the project is not vibe-coded. All AI-generated code is reviewed, tested, and held to my own quality standards before release.

## How AI is used
When AI is used, generated code serves as a starting point in areas where my own knowledge is lacking. I review the code, make corrections where needed, and progressively take over sections as I learn. Over time, AI-generated portions become smaller and I take over more of the work.
As far as the current state of the mod the AI usage breaks down as such

## Current State
- Mod/launcher: mostly AI generated (The next update is aimed at restructuring the mod and will involve most of this code switching over to human written code)
- APWorld: Entirely Human code

## Reverse Engineering
AI is also used heavily in finding memory addresses and functions to hook. This significantly speeds up development time and I have no plans to reduce AI use for this specifically.
