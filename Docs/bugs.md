# Known Bugs
- Chapters that happen in a skippable cutscene will not send their location if the cutscene is skipped
- Skull count in mission select does not always reflect the amount of skulls actually enabled. As long as the skull count in the mission is correct you are fine

## Reporting new bugs
Ensure that your bug is not one of the bugs listed above. If not ping @spencer2585 in the Halo the Master Chief Collection thread in the Archipelago Discord and I will add it to the list of bugs to be fixed and do what I can to help you get around it if needed
